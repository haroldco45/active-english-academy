# Active English Academy — App (PWA)

App web instalable de **Active English Academy**, academia de inglés 70% conversacional en Caucasia, Antioquia (stand en ExpoCaucasia 2026).

- Dirección: Cra 2da #26-26, 2do piso, Barrio El Carmen, Caucasia
- WhatsApp / teléfono: 311 708 2496
- Instagram: @activeenglishacademy · Facebook: Active English Academy

## Qué trae
- Portada animada con fotos reales del stand y textos que rotan
- Programas: niños (4 a 11), jóvenes (12 a 17), profesionales y empresarios
- Modalidades presencial, virtual y mixta (pestañas)
- Frase del día en inglés (cambia cada día, hora de Colombia) con botón para escuchar la pronunciación
- Test de nivel rápido (8 preguntas, A1–B2) que pasa el nivel al formulario
- Sala de conversación con chat animado
- Preinscripción que abre WhatsApp con el mensaje listo (aviso de Habeas Data, Ley 1581 de 2012; no guarda datos)
- Mapa, llamada, WhatsApp, Instagram y Facebook
- Español e inglés (botón EN/ES)
- PWA: manifest, service worker y botón Instalar app
- Vista previa del enlace (OG/Twitter) con `img/og.jpg` 1200×630

## Publicar
1. Subir todo al repo `haroldco45/active-english-academy` (respetando la carpeta `img/`).
2. Conectar el repo en Netlify con el nombre `active-english-academy` → https://active-english-academy.netlify.app
3. Si Netlify asigna otro nombre, cambiar la URL en las etiquetas `og:image`, `og:url` y `twitter:image` de `index.html`.
